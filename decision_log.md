# System Architecture & Engineering Decision Log

1. **Target Brand Selection (Delta Air Lines)**: Selected `@Delta` over `@AmazonHelp` because airline support presents rich, actionable operational resolutions (rebooking, baggage tracing, compensation policies) whereas e-commerce tweets predominantly default to opaque "DM us your order" dead-ends.
2. **Intent Taxonomy Cardinality (8 Clusters)**: Chose an 8-intent taxonomy with an explicit `other_unclear` catch-all because 3-4 intents is trivialized oversimplification while 25+ intents creates high data fragmentation and unmanageable per-class golden sample sizes.
3. **Dedicated `other_unclear` Intent & Mandatory Gating**: Included an `other_unclear` bucket to capture spam, non-English text, and uninterpretable fragments honestly rather than artificially forcing them into operational categories.
4. **Hybrid RAG Grounding over Fine-Tuning**: Selected retrieval grounding over fine-tuned weights because support policies change frequently and retrieved historical pairs provide transparent, verifiable audit trails for customer actions.
5. **Decoupled Modular Pipeline over Single Mega-Prompt**: Explicitly rejected a single LLM mega-prompt in favor of four isolated, typed stages (`classify -> retrieve -> draft -> decide`), enabling independent stage attribution and pinpoint failure isolation.
6. **Dual-Mode Reply Generation & Judging**: Built both deterministic offline synthesizers (~0.1ms latency) and live LLM API hooks (OpenAI / Gemini) so reviewers can execute benchmarks instantly with zero external dependencies while having full production LLM capabilities available.
7. **Asymmetric-Cost Decision Framing**: Framed auto-handling vs. escalation like a quantitative trading signal where false-positive auto-handling carries a severe $25 penalty versus a modest $2.50 escalation cost, justifying a conservative threshold.
8. **Explicit Decision Reasoning Strings**: Mandated that the decision engine output structured explanatory strings (e.g., `"escalated: retrieval similarity 0.24 < 0.40"`) rather than bare binary flags to ensure live operational explainability.
9. **Stratified Golden Set Quotas (Max 15% Cap)**: Capped any single intent at 15% of the 200-example golden set to prevent high-frequency delay inquiries from masking failures on rare, high-risk intents.
10. **Targeted Adversarial Edge Case Mining (19%)**: Injected 38 edge cases (sarcasm, emergency medical distress, PII leakage, legal threats) mined via keyword/regex queries from the raw 3M Kaggle corpus to test failure boundaries rather than curating an artificially pristine set.
11. **4-Dimensional LLM Judge Rubric**: Structured the quality judge into four named dimensions (*Groundedness*, *Correctness*, *Tone Fit*, *Actionability*) rather than a single holistic 1-5 score, exposing specific qualitative deficiencies like ungrounded fluency.
12. **Human-Judge Calibration Protocol**: Validated the LLM judge against a 40-sample human-annotated baseline and reported the correlation honestly, identifying that the judge systematically over-rewards fluent phrasing on ungrounded replies.
13. **Scope Exclusions (Zero Frontend / Single-Brand Focus)**: Deliberately omitted frontend dashboards and multi-brand routing to timebox focus entirely on pipeline defensibility, rigorous evaluation, and failure diagnostics.
14. **Rejection of AI-Suggested Zero-Shot Classification**: Discarded an AI coding assistant's suggestion to use zero-shot LLM classification on every tweet because it incurred 800ms+ latency and unpredictable calibration compared to calibrated TF-IDF/Logistic Regression (1.2ms latency).
